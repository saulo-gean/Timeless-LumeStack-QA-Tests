# 📖 Contexto do Projeto

Este projeto surgiu a partir de uma live do YouTuber Many, na qual foi apresentado o sistema **Timeless Lumestack** juntamente com uma documentação inicial para testes.

Em vez de apenas acompanhar o conteúdo, decidi transformar o aprendizado em uma experiência prática. Ampliei o escopo da atividade e utilizei o sistema como se estivesse atuando como **QA** em um projeto real.

O objetivo foi simular um ambiente profissional, explorando o sistema sob duas perspectivas:

* 👤 **Visão do Cliente**
* 🛠️ **Visão Administrativa (Admin)**

Durante a execução do projeto, realizei:

* Testes funcionais;
* Testes negativos;
* Testes exploratórios;
* Testes de regressão;
* Registro formal de bugs com evidências.

Mais do que identificar falhas, o foco foi desenvolver o pensamento crítico, validar regras de negócio, analisar comportamentos inesperados e documentar todo o processo de forma estruturada, seguindo práticas comuns no dia a dia de um profissional de QA.

Este projeto representa a transformação do estudo em prática, demonstrando uma abordagem voltada para qualidade contínua, visão analítica e evolução constante no processo de testes de software.
